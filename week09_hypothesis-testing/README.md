> 📩 "잔액이 많은 고객이 가입을 더 많이 한다는 게 통계적으로 유의하다던데, 그럼 잔액 많은 고객만 공략하면 되겠네요? 직업별로도 차이가 있는지 봐주세요." — 마케팅팀장

**케이스 질문:** 가입자와 미가입자의 잔액 차이는 **의미 있는** 차이인가? 직업별 가입률은 다른가?

**AI에게 먼저:** "balance 차이가 통계적으로 유의한지 검정해줘."

## 필수 과제

- [ ] `balance` 가입자 vs 미가입자: t-test, Welch t-test, Mann-Whitney + 평균 차이의 부트스트랩 95% 신뢰구간 + Cohen's d
- [ ] 표본 크기를 200, 2,000, 20,000으로 바꿔가며 같은 검정을 반복 → p값이 어떻게 변하는지
- [ ] `job` × `y` 카이제곱 검정 + 표준화 잔차로 어느 직업이 차이를 만드는지
- [ ] `education`별 `balance` ANOVA + Levene 등분산 검정 → 가정이 깨지면 Kruskal-Wallis

## 심화 과제

- [ ] 16개 변수를 전부 검정해 유의한 개수 세기 → Bonferroni 보정 후 개수 → 유일하게 유의하지 않은 변수는 정말 관계가 없는지
- [ ] 무작위 노이즈 변수 20개를 만들어 작은 표본에서 검정 → 우연히 유의한 개수
- [ ] 통화 스크립트 개선 효과를 확인하는 A/B 테스트 설계서: 가설, 지표, 필요 표본 수, 기간 (14.5)

## 토론 질문

- "통계적으로 유의하다"와 "공략할 만한 차이다"는 어떻게 다를까?
- 데이터가 4만 개가 넘을 때 p값은 어떤 정보를 주고, 어떤 정보를 못 줄까?
