## 🎯 사용 데이터: 🐱 Cookie Cats (메인) + 💳 Home Credit (비교)

**왜 이 데이터?** bank와 Home Credit은 관측 데이터라 "유의하다"가 곧 "원인이다"가 아님. Cookie Cats는 실제 무작위 배정 실험이라 검정 결과를 "게이트를 되돌릴까"라는 의사결정으로 연결할 수 있는 유일한 데이터이고, 9만 명 규모라 "큰 표본에서는 작은 차이도 유의하다"는 문제도 그대로 보임. Home Credit은 변수가 120개라 다중검정과 관측 데이터의 한계를 대조하는 용도.

**유의깊게 봤으면 하는 것**

- 검정 전에 실험이 제대로 됐는지(SRM) 먼저 확인
- p값보다 차이의 크기(%p)와 신뢰구간
- 1일·7일 리텐션이 같은 방향인지, 게이트에 도달하지 못한 유저가 효과를 희석하는지
- 같은 "유의"라도 실험 데이터와 관측 데이터는 다르게 말해야 함

## 필수 과제 — 🐱 Cookie Cats

- [ ] SRM 체크: 두 그룹 인원이 50:50 배정으로 설명되는지 카이제곱 적합도 검정
- [ ] `retention_1`, `retention_7`: 그룹별 비율, 차이(%p), 두 비율 검정(카이제곱 또는 z-test), 부트스트랩 95% 신뢰구간
- [ ] `sum_gamerounds`: t-test, Welch t-test, Mann-Whitney 비교 + 극단값 포함/제외 + Cohen's d
- [ ] 전체에서 200, 2,000, 20,000명을 뽑아 `retention_7` 검정을 반복 → 표본 크기에 따라 p값 분포가 어떻게 변하는지

## 필수 과제 — 💳 Home Credit (관측 데이터와 비교)

- [ ] `NAME_INCOME_TYPE` × `TARGET` 카이제곱 + 표준화 잔차로 어느 유형이 차이를 만드는지 (기대빈도 5 미만 범주 처리 포함)
- [ ] `NAME_EDUCATION_TYPE`별 `AMT_INCOME_TOTAL` ANOVA + Levene 등분산 검정 → 가정이 깨지면 Kruskal-Wallis

## 심화 과제

- [ ] Home Credit 수치 변수 전부를 부도/정상 그룹으로 검정해 유의한 개수 세기 → Bonferroni·BH 보정 후 개수
- [ ] 무작위 노이즈 변수 20개를 만들어 작은 표본에서 검정 → 우연히 유의한 개수
- [ ] Cookie Cats 후속 실험 설계서: 7일 리텐션에서 1%p 차이를 잡으려면 그룹당 몇 명이 필요한지(검정력 80%, α 0.05), 기간, 함께 볼 보조 지표 (14.5)

## 🔍 진행 가이드 & 유의할 점

### 도입 — Marketing A/B Testing (10분)

1. 처리군(ad)과 대조군(psa) 인원 비율 확인 → 약 96% vs 4%로 크게 불균형
2. "이 실험 설계는 뭐가 문제일까?" → 대조군이 작으면 추정이 불안정하고, 배정이 정말 무작위였는지도 의심됨
3. "좋은 실험의 조건"을 정리한 뒤 Cookie Cats로 ("이 실험은 조건을 만족하나?")

### Cookie Cats에서 유의해서 볼 것

- 검정 전에 **SRM부터**. 두 그룹 인원이 50:50 배정으로 설명되지 않으면 이후 검정은 의미가 없음
- `retention_1`, `retention_7`은 True/False → `.mean()`이 곧 비율. 차이는 %p로 보고
- 30레벨에 가지 못한 유저는 게이트를 만나지도 않음 → 처리 효과를 받지 않은 유저가 섞여 효과가 희석됨. `sum_gamerounds`가 작은 유저 비율 확인 (판 수 ≠ 레벨이라 근사임을 명시)
- `sum_gamerounds` 극단값 한 명(수만 판)이 평균 비교를 흔듦 → 6주차 기준으로 처리하고 포함/제외 둘 다 보고
- 9만 명이면 작은 차이도 유의하기 쉬움 → 차이 크기(%p)와 부트스트랩 신뢰구간을 먼저, p값은 그다음
- 1일과 7일 리텐션의 방향과 크기를 같이 보기. 원하는 쪽 하나만 골라 보고하면 그것도 데이터 마사지
- 표본 크기 실험은 seed 고정 + 여러 번 반복해 p값 분포로 보기. 한 번 뽑은 결과로 결론 내리지 않기

### Home Credit에서 유의해서 볼 것

- 30만 행이면 거의 모든 변수가 유의하게 나옴 → "몇 개가 유의한가"보다 효과 크기 분포를 보기
- 관측 데이터의 유의 = "관련 있음"이지 원인이 아님 (소득 유형 뒤에 나이·고용 형태 같은 교란변수)
- `NAME_INCOME_TYPE`의 소수 범주(Businessman, Student 등)는 기대빈도 5 미만 → 합치거나 정확검정

### AI 검증 포인트

SRM 확인 없이 바로 검정하는지, p값만 보고 "되돌리세요"라고 결론 내는지, 효과 크기·신뢰구간·희석 문제를 언급하는지, Home Credit 결과를 인과로 표현하는지
