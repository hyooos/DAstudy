> 📩 "상담원들이 통화를 길게 하면 가입이 늘어나는 것 같다던데, 통화 시간을 늘리라고 지시해도 될까요?" — 마케팅팀장

**케이스 질문:** 통화시간이 길면 가입하게 된다고 말할 수 있나?

**AI에게 먼저:** "가입 여부와 가장 관련이 큰 변수를 상관분석으로 찾아줘."

## 필수 과제

- [ ] 수치형 변수와 `y`의 피어슨·스피어만 상관, 수치형 변수끼리 상관행렬 + 산점도 행렬(10.6)
- [ ] `pdays`와 `y`의 상관을 **-1 포함 / -1 제외 / "이전 연락 여부" 파생변수**로 세 번 계산
- [ ] `campaign`을 구간(1, 2, 3, 4~5, 6~10, 11+)으로 나눠 가입률 그래프
- [ ] `duration`을 10분위로 나눠 가입률 그래프
- [ ] 범주형 변수와 `y`의 Cramér's V 계산 → 가장 관련이 큰 범주형 변수 찾기

## 심화 과제

- [ ] `duration`과 가입의 관계가 연도별로 나눠도 유지되는지 확인 → 유지된다면 인과라고 할 수 있는지
- [ ] `month`별 가입률과 건수를 같이 보기 → 가입률이 높은 달의 표본 크기는?
- [ ] `age`는 상관계수가 거의 0인데 정말 가입과 관계가 없는지 (연령대별 가입률)

## 토론 질문

- 팀장에게 "통화 시간을 늘리라"고 해도 될까? 안 된다면 대신 무엇을 제안할까?
- 상관계수 표만 보고 변수를 고르면 무엇을 놓치게 될까?
