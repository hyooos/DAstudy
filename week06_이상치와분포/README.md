### Home Credit에서 유의해서 볼 것

- 5주차 처리(`fix_days_employed()`)를 **먼저** 적용하고 이상치를 볼 것. 365243을 그대로 두면 IQR·z-score 모두 이상치로 잡는데, 이건 이상치가 아니라 코드값 → 순서가 바뀌면 결과가 달라짐
- `AMT_INCOME_TOTAL`은 꼬리가 극단적으로 길어서 원래 스케일 히스토그램은 막대 하나처럼 보임 → `np.log1p` 스케일로 모양부터 확인
- `DAYS_*`는 음수 일수 → `-x / 365`로 "년" 단위로 바꿔야 해석 가능
- `CNT_CHILDREN`처럼 값이 몇 개 안 되는 이산형 변수에 IQR을 쓰면 자녀 3명 이상이 전부 이상치가 될 수 있음 → 이산형 변수에 IQR이 맞는지부터
- 소득 최댓값 행은 직접 열어서 대출액·상환액·소득 유형과 맞는지 보기. 다른 열과 모순되면 오류 쪽, 일관되면 진짜 극단값 쪽
- z-score 3 기준은 평균·표준편차가 극단값에 끌려가서 치우친 변수에선 잘 안 맞음 → 두 기준의 개수가 왜 다른지 설명
- 파생 비율(대출액/소득)은 분모가 작을 때 폭발 → 비율의 극단값은 분모부터 확인
- 제거 전후 **부도율 비교는 필수**. 고소득·고액 대출 신청자를 지우면 부도율이 어느 쪽으로 움직이는지

#### 10.5 분포 시각화

- 양적 척도는 히스토그램, 질적 척도는 파이·도넛·트리맵·와플 차트로 그린다.
- 히스토그램은 처음에 구간을 20개 정도로 촘촘하게 나눠 보고 조금씩 줄여 간다. 구간이 너무 많으면 읽기 어렵고, 너무 적으면 정보가 사라진다.
- 봉우리가 두 개면 성격이 다른 집단이 섞였다는 신호다 (교재 예: 남녀 키). 집단별로 나눠 `density=True`로 겹쳐 본다.
- 이번 주 연결: Part 1. 소득은 원래 스케일에서 막대 하나로 뭉치므로 로그 스케일로 모양부터 본다. 로그 소득을 구간 100개로 나누면 135,000처럼 반올림한 값에 몰린 막대가 보인다 (1-7).

#### 10.8 박스 플롯

- 다섯 수치: 아래 수염 끝, Q1, 중앙값, Q3, 위 수염 끝. 상자 길이가 IQR(Q3 − Q1)이다.
- 수염은 Q1 − 1.5·IQR, Q3 + 1.5·IQR 경계 **안쪽의 실제 최솟값·최댓값**까지 그린다. 경계 밖의 점이 이상치 후보다.
- 정규분포라면 1.5·IQR 경계는 ±2.698σ이고, 그 밖에 놓이는 비율은 약 0.7%다.
- 중앙값이 상자 아래쪽에 있고 위 수염이 길면 오른쪽 꼬리 분포다.
- 집단별 박스플롯에 평균(`showmeans`)과 실제 점(`stripplot`)을 더하면 평균과 중앙값의 차이, 점이 몰린 곳까지 보인다.
- 이번 주 연결: Part 1(부도 여부별 로그 소득 박스플롯), Part 3(IQR 기준).

#### 11.2 이상치 처리

- 이상치는 평균과 분산을 왜곡하고 회귀선을 끌어당긴다. 데이터가 많을수록 영향은 줄어든다.
- 처리 방법
  - 제거(trimming): 가장 간단하지만 분산이 줄어 실제보다 작게 추정된다.
  - 상·하한 대체(value modification): 경계 밖 값을 경계값으로 바꾼다.
  - 가중치 조정(weight modification): 이상치의 영향을 줄이는 가중치를 준다.
- 탐지 기준
  - 박스플롯 기준 IQR×1.5. 교재 실습은 실무 데이터의 꼬리를 고려해 IQR×3을 쓴다.
  - 평균 ± n·σ (보통 n = 3). 분포가 치우치면 양쪽 n을 다르게 둔다.
  - 평균·표준편차는 이상치에 끌려가므로 중앙값과 MAD(중위수 절대 편차)가 더 강건하다.
- 통계 기준만으로 판단하면 위험하다. 나이 225세는 바로 오류로 볼 수 있지만, 다른 집단(전문직)이 섞여 생긴 이상치는 지우는 대신 변수로 만들어 설명력을 높일 수 있다.
- 교재 정정: p.223의 "IQR×3은 약 5σ"는 계산하면 ±4.72σ, p.199의 "수염 끝은 평균 좌우 3표준편차"는 ±2.698σ다.
- 이번 주 연결
  - Part 2: 365243을 처리하지 않으면 z>3이 0개 → 코드값 처리가 먼저
  - Part 3: 소득 이상치가 기준에 따라 454개(z>3)에서 14,035개(IQR×1.5)까지 달라짐
  - Part 4: 소득 1위 1.17억 행을 직접 열어 다른 열과 모순되는지 확인
  - Part 5: 일괄 삭제하면 13% 삭제, 부도율 8.07% → 8.46%
