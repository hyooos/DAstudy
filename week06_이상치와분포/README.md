## 데이터 선정 이유

소득(`AMT_INCOME_TOTAL`)의 극단값, 이상치처럼 보이는 코드값(`DAYS_EMPLOYED` 365243), 논리 점검이 필요한 값(자녀 수, 소득 대비 대출액)까지 **오류 / 코드값 / 진짜 극단값 / 통계적으로만 드문 값** 네 종류가 한 데이터에 다 있습니다.
대출 데이터라 "고소득자 빼자"가 부도율 결론을 실제로 바꿀 수 있어서 토론이 현실적입니다.

**분석 포인트**

- 지우기 전에 해당 행을 직접 열어 다른 열과 논리적으로 맞는지 확인
- 5주차 코드값 처리를 **먼저**, 이상치 판단은 그다음 (순서가 바뀌면 결과가 달라짐)
- 꼬리가 긴 변수는 로그 스케일로 모양부터
- 제거 전후 부도율 비교

- **케이스 질문:** `AMT_INCOME_TOTAL`, `AMT_CREDIT`, `DAYS_EMPLOYED`의 극단값은 지워야 하나? 오류와 진짜 극단값은 어떻게 구분하나?
- **AI에게 먼저:** "IQR 방식으로 이상치를 제거해줘."

## 과제

### 필수

- [ ] `AMT_INCOME_TOTAL`, `AMT_CREDIT`, `AMT_ANNUITY`, `CNT_CHILDREN`, `DAYS_EMPLOYED`, 나이(`-DAYS_BIRTH / 365`)의 히스토그램·박스플롯(10.5, 10.8) — 원래 스케일과 로그 스케일 둘 다
- [ ] 변수별로 IQR 기준 / z-score 3 기준 이상치 개수 비교
- [ ] 이상치로 잡힌 신청자 vs 나머지 신청자의 부도율
- [ ] 소득 최댓값 행을 직접 열어 대출액·상환액·소득 유형 등 다른 열과 논리적으로 맞는지 확인
- [ ] 위 변수 중 하나라도 IQR 이상치인 행을 모두 지웠을 때 남는 행 수와 부도율

### 심화

- [ ] 파생 비율 `AMT_CREDIT / AMT_INCOME_TOTAL`, `AMT_ANNUITY / AMT_INCOME_TOTAL`(소득 대비 상환 부담)의 극단값 → 원 변수에선 정상인데 비율에선 튀는 행 찾기
- [ ] `AMT_INCOME_TOTAL`을 제거 / 상한 처리(1%, 99%) / 로그 변환 / 그대로 두기 네 방식으로 부도자·정상 상환자 대표값 비교
- [ ] 이번 주 발견한 값들을 **오류 / 코드값 / 진짜 극단값 / 통계적으로만 드문 값** 네 종류로 분류한 표 만들기

## 진행 가이드

### 도입 — California Housing (10분)

1. `MedHouseVal` 히스토그램 → 오른쪽 끝(5.0)에 뾰족한 막대
2. "이상치인가?" 투표 → 실제로는 상한에서 잘린 값(절단)
3. `HouseAge`도 52에서 같은 현상 → 이번 주 목표는 **오류 / 절단 / 진짜 극단값 / 통계적으로만 드문 값**을 구분하는 것

### Home Credit에서 유의해서 볼 것

- 5주차 처리(`fix_days_employed()`)를 **먼저** 적용하고 이상치를 볼 것. 365243을 그대로 두면 IQR·z-score 모두 이상치로 잡는데, 이건 이상치가 아니라 코드값 → 순서가 바뀌면 결과가 달라짐
- `AMT_INCOME_TOTAL`은 꼬리가 극단적으로 길어서 원래 스케일 히스토그램은 막대 하나처럼 보임 → `np.log1p` 스케일로 모양부터 확인
- `DAYS_*`는 음수 일수 → `-x / 365`로 "년" 단위로 바꿔야 해석 가능
- `CNT_CHILDREN`처럼 값이 몇 개 안 되는 이산형 변수에 IQR을 쓰면 자녀 3명 이상이 전부 이상치가 될 수 있음 → 이산형 변수에 IQR이 맞는지부터
- 소득 최댓값 행은 직접 열어서 대출액·상환액·소득 유형과 맞는지 보기. 다른 열과 모순되면 오류 쪽, 일관되면 진짜 극단값 쪽
- z-score 3 기준은 평균·표준편차가 극단값에 끌려가서 치우친 변수에선 잘 안 맞음 → 두 기준의 개수가 왜 다른지 설명
- 파생 비율(대출액/소득)은 분모가 작을 때 폭발 → 비율의 극단값은 분모부터 확인
- 제거 전후 **부도율 비교는 필수**. 고소득·고액 대출 신청자를 지우면 부도율이 어느 쪽으로 움직이는지

### AI 검증 포인트

- 365243을 "이상치"로 보고 제거하는지 (코드값인데)
- 모든 수치 열에 IQR을 일괄 적용하는지
- 제거 후 남은 행 수와 부도율을 보고하는지

- 소득 최댓값 행을 캡처해 "이 사람은 진짜일까?"로 토론 시작
