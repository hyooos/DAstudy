## 데이터 선정 이유

행이 날짜순인데 연도 열이 없어서 "데이터에 없는 변수가 결론을 뒤집는" 심슨의 역설을 직접 복원해볼 수 있습니다.
평균·중앙값이 반대 방향인 `age`, 음수·극단값이 있는 `balance`, 코드값 -1이 섞인 `pdays`까지 대표값의 함정이 한 데이터에 다 모여 있습니다.

**분석 포인트**

- 척도는 판정 결과보다 **판정 근거**가 중요
- "숫자 하나만" 요청이어도 분포를 먼저 보고, 어떤 대표값이 "전형적인 고객"을 말하는지 고르기
- 전체 비교와 하위 집단(연도) 비교의 방향이 달라지는지

### Bank에서 유의해서 볼 것

- 척도 판정은 결과보다 **근거**가 중요. `day`, `month`는 숫자처럼 보여도 크기 비교가 무의미(월은 순환), `education`은 서열이지만 unknown의 위치를 정해야 함, `pdays`는 -1 때문에 그대로 비율척도로 보면 안 됨
- 평균·중앙값 반대 방향: `age`가 대표 사례. 반대라는 걸 찾는 데서 끝내지 말고 연령대별 가입률(U자) 그래프로 **왜** 그런지까지 설명해야 완성
- `balance`: 평균이 중앙값의 약 3배, 최빈값은 0. 음수·0 개수를 같이 보고 "전형적인 고객"을 무엇으로 보고할지 근거 쓰기
- 경험법칙: `balance`의 ±1·2·3σ 비율이 68-95-99.7에서 크게 벗어남 → 어느 방향으로 벗어나는지 해석하면 "정규가 아니다"의 수치 근거가 됨
- `pdays` 평균: -1 포함 약 40일 vs 제외 약 225일 → 코드값 하나가 대표값을 얼마나 망가뜨리는지. 가입자/미가입자 비교 방향도 뒤집힘 (포함 69 vs 36, 제외 193 vs 234)
- 연도 복원: `month`를 1~12로 매핑 → `month_num.diff() < 0`인 지점마다 연도 +1 (2008년은 5월 시작). 결과가 2008~2010 세 해로 나오는지 검증 (더 많이 나오면 정렬이 깨진 구간이 있다는 뜻)
- 연도별 가입률이 약 5% → 17% → 52%로 크게 달라서, 연도 구성이 다른 그룹끼리 전체로 비교하면 뒤집힐 수 있음. 전체 가입률은 연도별 가입률을 연도 비중으로 **가중평균**한 값 (교재 4.1), 연도는 통제해야 할 제3의 변수 (교재 3.1·3.2)
- 심슨의 역설은 모든 조합에서 뒤집히지 않음. 뒤집히지 않은 경우도 결과로 기록하기

#### 3.1 변수의 종류

- 독립변수는 원인, 종속변수는 결과에 해당한다. 분석은 종속변수(현상)를 설명할 수 있는 독립변수(원인 후보)를 찾는 일이다.
- 독립변수끼리는 상관이 낮을수록 좋다. 독립변수끼리 상관이 높으면 각 변수가 종속변수에 주는 영향을 따로 떼어 보기 어렵다 (다중공선성, week10).
- 원인과 결과 말고도 역할이 다른 변수가 있다.
  - 통제변수: 종속변수에 영향을 줄 수 있어 고정하거나 나눠서 봐야 하는 외부 요인 (시간, 날씨 등)
  - 매개변수: 독립변수의 영향을 종속변수에 전달하는 중간 변수
  - 조절변수: 독립변수와 종속변수 관계의 강도나 방향을 바꾸는 변수

#### 3.2 변수 관계

| 관계 | 뜻 | 예 |
| --- | --- | --- |
| 인과관계 | 한 변수가 다른 변수의 원인 | 독립변수 → 종속변수 |
| 상관관계 | 함께 움직이는 관련성. 인과가 있으면 상관이 나타나지만, 상관이 있다고 인과인 것은 아님 | |
| 독립관계 | 서로 관련이 없음. 독립이면 상관계수는 0이지만, 상관계수가 0이어도 독립이 아닐 수 있음 (비선형 관계) | |
| 의사관계 | 상관은 있지만 제3의 변수 때문에 생긴 관계 | 아이스크림 판매량과 익사 사고 (원인은 기온) |
| 양방향 인과 | 서로 영향을 주고받음 | 투자 → 매출 증가 → 추가 투자 |
| 조절관계 | 제3의 변수에 따라 관계의 강도·방향이 달라짐 | 업무 만족도와 매출의 관계가 성별에 따라 다름 |

#### 4.1 중심성향

데이터를 대표하는 값 하나를 고를 때 쓰는 값이다.

- 산술평균: 모든 값을 더해 개수로 나눈 값. 등간·비율척도에 쓴다. 극단값에 민감하다.
- 가중평균: 비중이 다른 값에 가중치를 주어 구한 평균 (예: 품목별 가중치를 둔 소비자물가지수). 여러 집단의 전체 비율은 집단별 비율을 집단 크기로 가중평균한 값이다 (심슨의 역설과 연결).
- 기하평균: 곱해서 누적되는 비율의 평균. 성장률, 물가상승률, 수익률에 쓴다 (예: 10만원 → 1년 뒤 20만원 → 다음 해 10만원이면 평균 수익률은 0%).
- 조화평균: 역수의 평균의 역수. 같은 거리를 다른 속도로 갔을 때 평균 속도처럼, 분모 기준이 같은 비율을 평균할 때 쓴다.
- 중앙값: 크기 순으로 가운데 값. 소득처럼 한쪽으로 치우친 데이터에서 체감에 가까운 대표값이다.
- 최빈값: 가장 많이 나온 값. 명목척도에도 쓸 수 있고, 두 개 이상일 수 있다 (봉우리가 여러 개인 분포). 예: 생산할 옷·신발 사이즈 비중 결정.
- 이번 주 연결: Part 3. `age`는 평균과 중앙값이 반대 방향, `balance`는 평균 1,362 / 중앙값 448 / 최빈값 0.

#### 4.2 분산과 표준편차

- 분산은 편차(값 − 평균)를 제곱해 평균한 값이고, 표준편차는 그 제곱근이다. 단위가 원래 값과 같아서 표준편차를 주로 쓴다.
- 편차의 절댓값 평균이 더 직관적이지만, 제곱을 쓰면 계산과 수학적 처리가 쉽고 여러 변수일 때 유클리드 거리와 같은 구조가 된다.
- 표본으로 구할 때는 n이 아니라 n − 1(자유도)로 나눈다.

#### 4.3 범위, 사분위수, 변동계수

- 범위: 최댓값 − 최솟값. 극단값 하나에 크게 흔들린다.
- 사분위수: 크기 순으로 4등분한 경계값 (25%, 50%, 75%). IQR(75% − 25%)은 극단값에 덜 민감한 퍼짐 지표다.
- 변동계수(CV): 표준편차 ÷ 평균. 평균이 다른 두 자료의 상대적인 퍼짐을 비교할 때 쓴다. 비율척도에서만 의미가 있다.

#### 4.4 왜도와 첨도

- 왜도: 분포가 한쪽으로 치우친 정도.
  - 양의 왜도 (오른쪽 꼬리): 작은 값이 많고 큰 값이 일부. 대체로 최빈값 < 중앙값 < 평균. 예: 소득, 매출, 주택 가격, 조회수
  - 음의 왜도 (왼쪽 꼬리): 큰 값이 많고 작은 값이 일부. 대체로 평균 < 중앙값 < 최빈값. 예: 쉬운 시험 점수, 만족도 점수
- 첨도: 꼬리가 얼마나 두꺼운지(극단값이 얼마나 자주 나오는지)를 나타낸다.
- 왜도가 생기는 이유: 0 아래로 내려갈 수 없는 값(소득, 가격, 횟수), 일부 극단값(VIP 고객), 상한·하한에 몰리는 값(만족도).
- 왜도 자체가 문제는 아니다. 쓰는 방법이 왜도에 민감할 때 대응한다.
  - 평균과 중앙값을 함께 보기, 극단값을 따로 확인하기
  - 변환: 로그(강한 양의 왜도), 제곱근(횟수 데이터), Box-Cox(양수만), Yeo-Johnson(0과 음수도 가능)
  - 트리 기반 모델(랜덤포레스트, XGBoost, LightGBM)은 분포 모양에 크게 민감하지 않다.
- 이번 주 연결: `balance`는 왜도 8.4, 음수·0이 있어 로그 변환을 바로 쓸 수 없다.

#### 4.5 경험법칙과 체비셰프 정리

- 경험법칙: 정규분포라면 평균 ± 1σ, 2σ, 3σ 안에 각각 약 68%, 95%, 99.7%가 들어간다. 표본이 충분히 크고(대략 100 이상) 분포가 정규에 가까울 때 쓴다.
- 체비셰프 정리: 분포 모양과 상관없이 평균 ± kσ 안에 최소 1 − 1/k²이 들어간다 (k=2이면 75%, k=3이면 약 89%).
- 이번 주 연결: Part 3-4. `balance`는 ±1σ 안에 92%가 들어가 경험법칙에서 크게 벗어나고, 체비셰프 하한은 지켜진다.

#### 5.5 심슨의 역설

- 전체로 본 결론과 하위 집단으로 나눠 본 결론이 반대가 되는 현상이다.
- 평균이나 비율은 정보를 압축한 값이라, 데이터를 어떻게 나누고 합치느냐에 따라 결과가 정반대로 바뀔 수 있다. 전체 비율은 집단별 비율을 집단 크기로 가중평균한 값이라서, 집단 구성이 다르면 뒤집힌다.
- 통계적 결론이 나오면 데이터가 어떻게 만들어졌는지까지 거슬러 올라가 원인을 확인하는 습관이 필요하다.
- 이번 주 연결: Part 0(버클리 입학), Part 5(연도 복원 후 `poutcome`, `job` 비교).
