> 📩 "가입한 고객과 안 한 고객이 어떻게 다른지 한 장짜리 표로 정리해 주세요. 임원 보고용이라 숫자 하나씩만요." — 마케팅팀장

**케이스 질문:** 각 변수를 대표값 하나로 보고한다면 무엇을 써야 하나? 그 표는 믿을 만한가?

**AI에게 먼저:** "가입자와 미가입자의 특성을 기술통계로 비교해줘."

## 필수 과제

- [ ] 17개 변수의 척도(명목·서열·등간·비율)를 판정해 변수 사전 채우기 → `docs/data_dictionary.md`
- [ ] `age`, `balance`, `duration`, `campaign`의 가입자/미가입자별 평균·중앙값 비교표 → **평균과 중앙값이 반대 방향을 가리키는 변수가 있는지** 찾기
- [ ] `balance`의 왜도, 음수·0 개수, 최빈값 확인 → 평균이 "전형적인 고객"을 대표하는지
- [ ] `balance`에서 평균 ±1·2·3σ 안에 들어오는 비율 → 경험법칙(68-95-99.7)과 비교
- [ ] `pdays`의 평균을 -1 포함 / 제외로 각각 계산

## 심화 과제

- [ ] 행 순서와 `month`로 **연도를 복원**하기 (월이 앞으로 돌아가면 해가 바뀐 것) → 연도별 건수와 가입률
- [ ] 직업(technician vs admin.) 또는 이전 캠페인 결과(unknown vs failure)의 가입률을 전체로 비교한 뒤 **연도별로 나눠서** 다시 비교

## 토론 질문

- 임원 보고용 표에 평균을 넣을까, 중앙값을 넣을까? 둘 다 넣는다면 어떻게 설명할까?
- 데이터에 없는 변수(연도)가 결론을 뒤집을 수 있다면, 우리는 그걸 어떻게 미리 의심할 수 있을까?
