## 데이터 선정 이유

`duration`은 가입과 상관이 매우 강하지만 가입 절차 때문에 통화가 길어지는 역인과 사례이고, `campaign`도 "가입하면 연락을 멈추는" 구조라 역인과입니다.
`age`는 상관 ≈ 0인데 U자 관계라서, 상관계수의 한계 세 가지를 한 데이터에서 다 볼 수 있습니다.

**분석 포인트**

- 상관을 "영향을 준다"로 말하지 않기. 화살표 방향(역인과)과 제3의 변수 의심하기
- 이진 타깃과의 상관은 원래 작게 나옴 → 크기만 보고 버리지 않기
- 코드값(-1)은 분리한 뒤 계산, 비율은 항상 건수와 함께

## 진행 가이드

### 도입 — Datasaurus Dozen (10분 퀴즈)

1. 13개 데이터의 평균·표준편차·상관계수 표만 보여주고 "모양이 같을까?"
2. 산점도 공개 (공룡 포함)
3. "상관계수 하나로 관계를 요약하면 안 되는 이유" 한 줄 정리 후 Bank로

### Bank에서 유의해서 볼 것

- `y`가 0/1이라 피어슨 상관 = 점이연 상관. 값이 작게 나오는 게 정상이니 "0.1이면 관계 없음"으로 읽지 말기
- `pdays` 세 번 계산: -1을 포함하면 "이전 연락 여부"와 "경과 일수" 두 정보가 섞임 → 플래그로 분리하면 어느 쪽이 가입과 관련 있는지 드러남
- `campaign` 구간별 가입률이 연락 많을수록 떨어짐 → "많이 전화해서 싫어한다"(인과)인지 "가입 안 한 사람에게 계속 전화해서"(역인과)인지. 가입하면 연락을 멈추는 구조라 역인과 가능성이 큼
- `duration`: 통화가 길수록 가입률이 오르지만 가입 절차 자체가 통화를 길게 만듦 → 팀장에게 "통화 늘리기" 대신 무엇을 제안할지로 연결
- `month`: 가입률이 높은 달(3·9·10·12월 등)은 건수가 적음 → 막대(건수) + 선(가입률) 한 그래프로
- `age`: 상관 ≈ 0이어도 연령대별 가입률은 U자 → 비선형 관계는 상관계수가 못 잡음
- Cramér's V는 범주 수가 많을수록 커지는 경향이 있음 → 비교할 때 범주 수도 같이 적기

### AI 검증 포인트

- 상관계수 순위만 제시하는지
- `duration`을 "가장 중요한 요인"으로 제시하는지
- `pdays` -1을 그대로 계산하는지, 상관을 "영향을 준다"로 표현하는지

### 발제자 준비

- `pdays`를 그대로 넣은 상관행렬 히트맵을 준비해 "이 숫자 믿을 수 있나?"로 시작
