# 분석 감사 체크리스트

내 분석과 AI 분석을 점검할 때 같이 씁니다. 매주 "쌓을 것"에 나온 항목을 추가하고, week10에서 최종본으로 정리합니다.
(초안 — 모임에서 다듬기)

## 공통
- [ ] 결론(핵심 결과 한 줄)이 노트북의 숫자와 일치하는가
- [ ] 이전 주차 결정(`decisions.md`)과 다른 처리를 했다면 이유를 적었는가

## week01 — 목적
- [ ] AI가 예측 시점을 명시했는가

## week02 — 표본
- [ ] AI가 표본의 범위와 대표성 한계를 언급했는가

## week03 — 척도·기술통계
- [ ] 척도에 맞지 않는 통계량을 쓰지 않았는가 (서열·명목 변수의 평균 등)
- [ ] 치우친 변수를 평균만으로 요약하지 않았는가

## week04 — 상관
- [ ] 상관을 인과로 표현하지 않았는가, 교란변수를 생각했는가
- [ ] 코드값(-1 등)을 숫자로 취급하지 않았는가

## week05 — 결측
- [ ] 숨은 결측(`unknown`, -1, 0, 빈 문자열)을 확인했는가
- [ ] 결측 처리 방식에 따라 결론이 바뀌는지 비교했는가

## week06 — 이상치
- [ ] 이상치 제거가 타깃 분포를 바꾸지 않았는지 확인했는가

## week07 — 누수·검증
- [ ] 예측 시점에 알 수 없는 변수(예: `duration`)를 쓰지 않았는가
- [ ] 전처리를 train에만 fit했는가
- [ ] 분할 방식이 실제 사용 상황과 맞는가

## week08 — 평가
- [ ] 정확도만으로 평가하지 않았는가
- [ ] 기준 모델과 비교했는가
- [ ] 샘플링을 train에만 적용했는가

## week09 — 검정
- [ ] 검정 가정을 확인했는가
- [ ] p값과 함께 효과 크기를 보고했는가
- [ ] 여러 번 검정했다면 보정했는가
- [ ] 유의한 차이를 인과로 표현하지 않았는가
