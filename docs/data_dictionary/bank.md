# 🏦 Bank Marketing 변수 사전 — `bank-full.csv`

사용 주차: 1·2·3·4·7·8

| 항목 | 내용 |
| --- | --- |
| 출처 | UCI Bank Marketing — 포르투갈 은행 전화 마케팅 기록, 2008년 5월 ~ 2010년 11월, **날짜 순으로 정렬** |
| 파일 | `bank-full.csv` — 45,211행 × 17열, 구분자 세미콜론(`;`) |
| 타깃 | `y` 정기예금 가입 여부 — yes 5,289건 (11.7%) |
| 불러오기 | `common.load_data.load_bank()` |
| 주의 | 고객 ID가 없음 → "행 수 = 고객 수"라고 쓰지 않기. 연도 열이 없음 (3주차 복원) |

- **척도** 열은 week03 필수 과제에서 채웁니다.
- **시점** 열은 week01 결정(D-001) 기준: **전** = 전화 걸기 전에 알 수 있음 / **후** = 통화 후에야 알 수 있음 / **애매** = 예측 시점 정의에 따라 다름 (근거 적기)

| 변수 | 설명 | 척도 | 시점 | 주의할 점 |
| --- | --- | --- | --- | --- |
| `age` | 나이 (18~95) |  |  | 가입률과의 관계가 직선이 아님 (U자) |
| `job` | 직업 12개 범주 |  |  | `unknown` 포함 |
| `marital` | 결혼 여부 |  |  |  |
| `education` | primary / secondary / tertiary / unknown |  |  | 순서가 있지만 `unknown` 포함 |
| `default` | 신용 불량 여부 |  |  | yes가 매우 적음 |
| `balance` | 연평균 잔액(유로) |  |  | **음수 존재**, 오른쪽 꼬리가 매우 김 |
| `housing` | 주택 대출 여부 |  |  |  |
| `loan` | 개인 대출 여부 |  |  |  |
| `contact` | cellular / telephone / unknown |  |  | `unknown`이 약 29% |
| `day` | 마지막 연락 일 |  |  | 숫자여도 크기 비교가 의미 없음. "마지막 연락" 날짜라 시점 문제 |
| `month` | 마지막 연락 월 |  |  | **연도 열이 없음**, 순환형 |
| `duration` | 마지막 통화 시간(초) |  |  | **통화가 끝나야 알 수 있음 → 사전 예측에 쓰면 누수** (UCI 설명에도 명시) |
| `campaign` | 이번 캠페인 연락 횟수 (마지막 연락 포함) |  |  | 꼬리가 김 (최대 63). 첫 통화 전엔 알 수 없음 |
| `pdays` | 이전 캠페인 연락 후 지난 일수 |  |  | **-1 = 이전 연락 없음** (숫자가 아니라 코드) |
| `previous` | 이전 연락 횟수 |  |  | `pdays`, `poutcome`과 얽혀 있음 |
| `poutcome` | 이전 캠페인 결과 |  |  | `unknown` 대부분이 이전 캠페인 없음 |
| `y` | 정기예금 가입 여부 (타깃) |  | — | yes 11.7% (불균형) |
