# 🐱 Cookie Cats 변수 사전 — `cookie_cats.csv`

사용 주차: 9. 발제자가 9주차 D-7에 이 표를 한 번 더 공유합니다.

| 항목 | 내용 |
| --- | --- |
| 출처 | Kaggle — 모바일 퍼즐 게임에서 첫 게이트(기다리거나 결제해야 넘어가는 지점)를 30레벨 → 40레벨로 옮기는 실험. 게임을 설치한 유저를 무작위 배정 |
| 파일 | `cookie_cats.csv` — 90,189행 × 5열 |
| 불러오기 | `common.load_data.load_cookie_cats()` |
| 주의 | 날짜 정보 없음. 30레벨까지 못 간 유저는 게이트를 만나지도 않음 → 처리 효과가 희석됨 |

| 변수 | 설명 | 주의할 점 |
| --- | --- | --- |
| `userid` | 유저 ID | 분석 변수 아님, 중복 여부만 확인 |
| `version` | `gate_30`(기존, 대조군) / `gate_40`(처리군) | 두 그룹 인원이 배정 비율대로인지(SRM) 먼저 확인 |
| `sum_gamerounds` | 설치 후 14일간 플레이한 판 수 | 0판 유저 다수, 극단값(수만 판) 존재. 판 수 ≠ 레벨 |
| `retention_1` | 설치 1일 뒤 접속 여부 (True/False) | `.mean()`이 곧 리텐션 비율 |
| `retention_7` | 설치 7일 뒤 접속 여부 (True/False) | 1일 결과와 방향이 같은지 함께 보기 |
