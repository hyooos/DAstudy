> 📩 "평균 잔액이 이상하게 높게 나와요. 부자 몇 명 때문인 것 같은데 빼고 다시 계산해 주세요." — 마케팅팀장

**케이스 질문:** `balance`와 `campaign`의 극단값은 지워야 하나?

**AI에게 먼저:** "IQR 방식으로 이상치를 제거해줘."

## 필수 과제

- [ ] `age`, `balance`, `duration`, `campaign`, `previous`의 히스토그램·박스플롯(10.5, 10.8)
- [ ] 변수별로 IQR 기준 / z-score 3 기준 이상치 개수 비교
- [ ] 이상치로 잡힌 고객들의 가입률 vs 나머지 고객의 가입률
- [ ] 네 변수 중 하나라도 IQR 이상치인 행을 모두 지웠을 때 남는 행 수와 전체 가입률

## 심화 과제

- [ ] `previous`에 IQR을 적용하면 어떤 고객들이 이상치가 되는지 → 이게 "이상치"가 맞는지
- [ ] `balance`를 제거 / 상한 처리(1%, 99%) / Yeo-Johnson 변환 / 그대로 두기 네 방식으로 가입자·미가입자 대표값 비교
- [ ] `duration`이 0이거나 몇 초인 행, `previous`의 최댓값처럼 **논리적으로 의심스러운 값**과 **통계적으로 드문 값** 구분
