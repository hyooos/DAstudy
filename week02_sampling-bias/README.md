## 🎯 사용 데이터: 🏦 Bank Marketing

**왜 이 데이터?** 은행이 골라서 전화한 고객만 담긴 데이터라 "표본 ≠ 모집단"이 자연스럽게 드러나고, 2008~2010년 금융위기 시기라 시간적 일반화 문제도 같이 볼 수 있음. `balance`는 꼬리가 매우 길어서 중심극한정리가 언제부터 통하는지 보기 좋음.

**유의깊게 봤으면 하는 것**

- 결과 문장마다 "누구에 대한 결과인지"(연락받은 고객) 붙이기
- 중심극한정리는 데이터가 정규가 되는 게 아니라 **표본평균의 분포** 이야기
- 표본이 특정 월(5월)에 몰린 게 이후 월별 분석에 어떤 영향을 줄지

## 🔍 진행 가이드 & 유의할 점

### 도입 — Adult

- `fnlwgt`를 가중치로 쓴 평균(`np.average(x, weights=df.fnlwgt)`)과 단순 평균을 나이·고소득 비율로 나란히 계산
- 성별·연령대별로 "행 수 비중 vs 가중치 합 비중"을 비교해 어느 집단이 과소·과대 대표됐는지 찾기
- 주의: `fnlwgt`는 주(state) 단위로 만든 가중치라 전국 단위 비교에 그대로 쓰기엔 한계가 있음 → 이것도 토론 포인트

### bank에서 유의해서 볼 것

- 모집단을 "은행 전체 고객"이 아니라 "이 기간 텔레마케팅 대상으로 선정된 고객"으로 적기. 은행이 이미 골라서 전화한 사람들이라 전체 고객과 성향이 다를 수 있음
- 고객 ID가 없어서 같은 고객이 여러 행에 나오는지 확인할 수 없음 → "행 수 = 고객 수"라고 쓰지 않기
- 월별 건수는 5월에 크게 몰려 있음 → 이후 월별 가입률을 볼 때 항상 건수와 같이 보기 (4주차 연결)
- 중심극한정리: 데이터가 정규가 되는 게 아니라 **표본평균의 분포**가 정규에 가까워지는 것. `balance`처럼 꼬리가 긴 변수는 n=30에서 여전히 치우친 게 정상 → 히스토그램 + Q-Q plot, 반복 1,000번 이상, seed 고정

### AI 검증 포인트

AI가 "은행 고객 전체의 성향"이라고 쉽게 일반화하는지, 표본 범위(포르투갈 한 은행 / 2008~2010 / 연락받은 고객)를 먼저 언급하는지

### 발제자 준비

금융위기 전후로 예금 금리 환경이 어떻게 달랐는지 한 줄 정리 → "지금 고객에게 일반화 가능?" 토론 시작용
