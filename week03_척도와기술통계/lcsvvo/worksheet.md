# 분석 워크시트 — weekNN / lcsvvo

> `weekNN_주제/<github-id>/worksheet.md` 로 복사해서 쓰세요.
> 방법 선택과 해석은 **AI 답변을 열어보기 전에** 먼저 적기 (4번까지 쓰고 나서 열기).

- 사용 데이터: 🏦 bank / 💳 home credit / 🐱 cookie cats / 보조:

## 1. 질문 번역
- 원래 질문: 가입 고객과 미가입 고객이 어떻게 다른지 한 장짜리 표로 정리한다. (변수당 숫자 하나)
- 통계 문제로 바꾸면: y(yes/no) 두 그룹의 변수별 대표값 비교한다.

## 2. 데이터 진단
- 사용 변수와 척도: 수치형, 범주형, day·month는 평균이 무의미
- 분포: 양의 왜도를 가진 분포가 많다.
- 결측: isnull은 0이지만 unknown과 pdays -1이 숨은 결측값
- 표본 크기, 그룹 구성: 45,211건, 은행이 골라서 전화한 고객만 포함한다.

## 3. 방법 선택
- 고른 방법: 치우친 변수는 중앙값, 범주형은 그룹별 비율, pdays는 -1 여부와 경과일로 분리, 연도 복원 후 연도별 비교한다.
- 버린 대안과 버린 이유: describe 평균. 극단값과 코드 때문에 결론이 왜곡된다.
- 필요한 가정과 점검 방법: 행이 날짜순 -> 연도 복원 후 assert로 검증한다.

## 4. 예측
- 예상 결과와 이유: poutcome, job 비교는 그룹이 몰린 연도가 달라 연도별로 나누면 뒤집힐 것이다.

## 5. 결과 읽기
- 효과 크기 / 신뢰구간: 연도별 가입률 5.1% -> 17.1% -> 51.6%. poutcome failure−unknown 차이는 전체 +3.4%p, 연도별 −2.1~−11.1%p. 신뢰구간은 미산출
- 가정 점검 결과: 연도 복원 검증 통과
- 예측과 달랐던 점: 뒤집힘은 예측대로이다. marital은 뒤집히지 않는다.

## 6. 인사이트
- 관찰: 가입자는 잔액이 많고 이전 캠페인 연락 경험이 많다. 전체 비교는 연도를 나누면 뒤집힌다.
- 해석: 연도가 버클리의 "학과" 역할을 하는 숨은 변수다.
- 시사점: 연도를 통제하지 않은 전체 비교는 보고에 쓰면 안 된다.
- 행동: 비교 전에 그룹별 연도 구성부터 확인한다.
- 한계: 연락받은 고객만 포함, 단변량 비교, 고객 ID 없다.

## 7. AI 비교
- AI의 결론: 가입자는 통화가 길고 잔액이 많으며 이전 캠페인 성공률이 높다. 월별 차이는 연도 효과일 수 있다고 의심만 한다.
- 나와 달랐던 점, 누가 맞았는지: AI는 연도를 검증하지 않아 poutcome과 month 해석이 틀렸다. 나는 연도 복원으로 뒤집힘을 확인했다. duration 누수를 명시한 것은 AI가 더 분명했다.
